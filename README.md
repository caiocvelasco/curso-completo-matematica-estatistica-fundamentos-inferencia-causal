# Fundamentos da Inferência Causal

This repository contains the website for the course **Fundamentos da Inferência Causal**, built with [Quarto](https://quarto.org/).

The project is a Quarto **website**, not a book. The final static website is rendered to `docs/` and published with GitHub Pages.

---

## 1. Install the System Requirements

Install on your computer:

- [Python](https://www.python.org/)
- [Quarto](https://quarto.org/docs/get-started/)
- [Git](https://git-scm.com/)

Check that they are available:

```bash
python --version
quarto --version
git --version
```

These tools are installed system-wide. Python packages specific to the project will be installed later inside `.venv`.

---

## 2. Clone the Repository

```bash
git clone <repository-url>
cd <repository-name>
```

---

## 3. Create the Python Virtual Environment

```bash
python -m venv .venv
```

Activate it.

### Windows

```bash
.venv\Scripts\activate
```

### macOS / Linux

```bash
source .venv/bin/activate
```

---

## 4. Install the Python Dependencies

With `.venv` activated:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

List the installed dependencies, just to check:

```bash
pip list
```

The packages listed in `requirements.txt` are installed inside `.venv`.

---

## 5. Project Structure

```text
.
├── .venv/                 # Python virtual environment

├── _quarto.yml            # Quarto configuration
```

---

## 6. Configure the Quarto Website

The website configuration lives in `_quarto.yml`.

```yaml
project:
  type: website
  output-dir: docs

website:
  title: ""
  description: "Fundamentos da Inferência Causal: um curso completo da base matemática e estatística"

  navbar:
    left:
      - text: "Início"
        href: "#topo"

      - text: "Motivação"
        href: "#motivacao"

      - text: "Objetivo"
        href: "#objetivo"

      - text: "Pré-requisitos"
        href: "#requisitos"

      - text: "Conteúdo"
        href: "#conteudo"

      - text: "Inscreva-se"
        href: "#formulario"

      - text: "Sobre"
        href: "#sobre"

  page-footer:
    left: "© 2026 Caio Velasco"
    right: "Construído com ❤️"

format:
  html:
    theme: flatly
    smooth-scroll: false
    css: styles.css
```

The important settings are:

```yaml
project:
  type: website
```

which defines the project as a website, and:

```yaml
output-dir: docs
```

which sends the rendered website to `docs/`.

---

## 7. Edit the Website

The main course content is written in the `.qmd` file.

The IDs such as:

```text
#motivacao
#objetivo
#requisitos
```

are used by the navigation bar in `_quarto.yml`.

Custom styling goes in:

```text
styles.css
```

Images go in:

```text
images/
```

---

## 8. Preview Locally

During development, run:

```bash
quarto preview
```

Quarto starts a local server such as:

```text
http://localhost:XXXX
```

Edit and save the `.qmd`, `styles.css`, or `_quarto.yml` files while the preview server is running.

Quarto will automatically rebuild the website.

Stop the server with:

```text
Ctrl + C
```

---

## 9. Render the Website

When the website is ready:

```bash
quarto render
```

The final static website will be generated inside:

```text
docs/
```

---

## 10. Publish with GitHub Pages

Commit the source files and rendered `docs/` directory:

```bash
git add .
git commit -m "Update website"
git push
```

In GitHub:

```text
Settings
→ Pages
→ Deploy from a branch
→ main
→ /docs
```

GitHub Pages will then serve the website generated by Quarto.

---

## Development Workflow

For normal day-to-day development:

```bash
.venv\Scripts\activate
quarto preview
```

After making changes:

```bash
quarto render
git add .
git commit -m "Update website"
git push
```

So the complete workflow is:

```text
Activate .venv
      ↓
quarto preview
      ↓
Edit website
      ↓
quarto render
      ↓
docs/
      ↓
git commit
      ↓
git push
      ↓
GitHub Pages
```
