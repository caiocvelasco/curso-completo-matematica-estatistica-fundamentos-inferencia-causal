# Fundamentos da Inferência Causal

This repository contains the website for the course **Fundamentos da Inferência Causal**, built with [Quarto](https://quarto.org/).

The project is a Quarto **website**, not a book. The final static website is rendered to `docs/` and published with GitHub Pages.
